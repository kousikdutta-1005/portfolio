Design System

A comprehensive guide to the visual language, components, and patterns that define Kousik Dutta's portfolio. Every element is crafted to communicate with clarity, precision, and delight.

Design Philosophy

Clarity. Precision. Delight.

This design system prioritizes content legibility and user comfort. It favors generous whitespace, typographic hierarchy, and subtle motion to create an experience that feels both premium and effortless.

Core Principles

◎

Clarity

Every element serves a purpose. Remove what doesn't communicate. Typography does the heavy lifting — the interface disappears so the work speaks for itself.

◫

Consistency

Repeatable patterns create trust. Spacing, color, and type follow strict scales so every page feels like part of the same considered whole.

▲

Hierarchy

Guide the eye naturally. Size, weight, and space create clear reading paths. The most important information is always immediately apparent.

✦

Delight

Subtle animations, smooth transitions, and thoughtful micro-interactions reward attention and make the experience feel alive without being distracting.

Motion Preferences

Reduced Motion: When prefers-reduced-motion: reduce is active, all animations are disabled or reduced to simple opacity fades. Scroll-triggered reveals become immediate. The testimonial marquee stops.

Do's & Don'ts

✓ Do
Use transitions for state changes (hover, active, focus). Keep durations under 400ms for UI feedback. Use the default easing curve for most interactions.
✗ Don't
Add animation for decoration alone. Use bouncy easings for functional UI. Animate layout properties (width, height) when transform alternatives exist.
✓ Do
Provide immediate visual feedback on interaction. Use opacity and transform for performant animations. Respect reduced-motion preferences.
✗ Don't
Block user interaction during animations. Use identical timing for all animations regardless of distance. Animate more than 2–3 properties simultaneously.
Writing

Content Guidelines

Words matter as much as pixels. Consistent voice and formatting create a cohesive experience that reinforces the design's intent.

Voice & Tone

Attribute Description Example
Confident State expertise without arrogance "I design systems that scale" not "I try to design good systems"
Concise Say more with fewer words "10+ years in product design" not "I have been working in the field of product design for over ten years"
Human Professional but approachable "Let's work together" not "Please submit your inquiry"
Specific Use concrete outcomes, not vague claims "Reduced onboarding time by 40%" not "Improved the user experience"

Formatting Rules

Rule Details
Line length Max 65–75 characters for body copy (enforced via max-width)
Paragraph spacing Use margin-bottom, not double line breaks
Numbers Use figures, not words: "10+" not "ten or more"
Percentages No space before %: "40%" not "40 %"
Ranges En dash, no spaces: "2019–2023" not "2019 - 2023"
Lists Parallel structure, no trailing punctuation unless full sentences
Testimonials Curly quotes, italic style: "Quote here."
✓ Do
Write headings that tell a story. Use action-oriented language. Lead with impact: results first, then context.
✗ Don't
Use jargon without context. Write passive voice when active is clearer. Use "Click here" — instead, make the link text descriptive.
